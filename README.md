# Client-Side Prediction and Server Reconciliation in a Multiplayer Game

**Project ID:** 2026-NP-01

**Supervisor:** Péter Novák

## Project Overview

This project focuses on improving responsiveness and synchronization in real-time multiplayer games.

The main objective is to develop a multiplayer prototype that demonstrates client-side prediction and server reconciliation under different network conditions, including latency, jitter, and packet loss.

The project will also investigate an additional synchronization technique, such as entity interpolation, and compare the results with a basic synchronization approach.

The emphasis is on networking algorithms, accurate game-state synchronization, and experimental evaluation rather than creating a visually complex game.
